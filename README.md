# UShape

Один `Shape` рисует скруглённую плашку uGUI, заливку, внутренний border, внешний outline, внутреннюю и внешнюю тень. Текст, значки и другие элементы добавляются обычными дочерними объектами.

## Установка

Требуется Unity 2022.3 LTS или новее, uGUI и графический API с поддержкой Shader Model 3.5. В Package Manager выберите **Add package from git URL** и вставьте адрес:

```text
https://github.com/rustamkhonoff/ushape.git
```

Для локального подключения можно скопировать пакет в `Packages/com.rustamkhonoff.ushape`. Создайте объект через **GameObject → UI → Shape** или откройте один из примеров через то же меню. Инспектор работает без Odin.

## Настройка

- **Appearance** содержит Base Color, настройки заливки и раздел углов. В разделе **Corner Radius** поле **All Corners** задаёт одинаковый радиус для всех углов. Четыре поля ниже позволяют менять углы по отдельности. При разных радиусах общее поле показывает прочерк. Радиусы задаются в единицах RectTransform и пропорционально уменьшаются, если соседним углам не хватает места.
- **Appearance → Pointer** добавляет треугольный указатель к выбранной стороне. Position задаётся от 0 до 1 слева направо или снизу вверх, Width и Height — в единицах RectTransform. Основание остаётся на прямом участке между скруглениями. Рамка, контур и тени огибают указатель, а заливка продолжается в него. Попробуйте **GameObject → UI → Shape Tooltip Example**.
- В **Edges** друг за другом идут **Border** и **Outline**, в **Shadows** — **Outer Shadows** и **Inner Shadows**. При переключении верхней вкладки подсветка плавно смещается, а содержимое появляется с коротким переходом. Выбранная вкладка сохраняется при пересоздании инспектора в пределах сессии Unity. Настройки взаимодействия собраны в **Interaction**.
- **Edges → Border** и **Outline** имеют независимые Pattern, цвет или градиент и Animation. У **Dashed** настраиваются длина штриха и зазор. У **Dotted** диаметр точки берётся из толщины линии. Phase сдвигает рисунок в долях цикла. **March** перемещает штрихи и точки по периметру, **Pulse** плавно меняет прозрачность линии. Speed задаёт циклы в секунду. Отрицательная скорость разворачивает March. Пример доступен через **GameObject → UI → Shape Dashed Example**.
- `Fill`, `Border`, `Outline`: `Solid`, `Linear`, `Radial`, `Angular`, `Diamond`. Для градиента используйте стандартный Unity Gradient с несколькими цветами и alpha keys. `Color` умножается на выбранную заливку. `Angle` — в градусах против часовой стрелки, 0 у линейного градиента направлен вправо; `Center` и `Scale` заданы относительно размера плашки; `Offset` сдвигает градиент вдоль шкалы цветов. Градиенты ограничиваются крайними цветами, угловой циклический.
- `Border Width` расположен внутри RectTransform, `Outline Width` — снаружи. Тени имеют цвет, включение, сдвиг, мягкость и расширение. Смещение Y положительно вверх. Внутренние тени обрезаются формой самой плашки. **+ Add Shadow** добавляет слой, **↑/↓** меняют порядок, **−** убирает слой. Первый слой ближе всего к плашке. Для объёмной кнопки поставьте первым цветной слой с `Blur = 0`, а следующим мягкую чёрную тень.
- `Base Color` умножает результат всех слоёв; alpha заливки не меняет alpha обводки, рамки или тени. `CanvasGroup` работает через стандартный CanvasRenderer. Поддерживается вложенность в uGUI `Mask` и `RectMask2D`, включая параметр Softness.
## Изменения из кода

Публичные свойства `Shape` и вложенных настроек автоматически ставят обновление в очередь. Если за кадр изменить несколько свойств, стиль записывается один раз перед отрисовкой Canvas.

```csharp
using RustamKhonoff.UShape;
using UnityEngine;

public static class ShapeExample
{
    public static void Style(Shape shape)
    {
        shape.CornerRadii = new Vector4(24, 8, 24, 8);
        shape.Fill.Type = GradientType.Linear;
        shape.Fill.Angle = 90;
        shape.Fill.Color = new Color(1, 1, 1, .5f);
        shape.BorderWidth = 3;
        shape.Border.Color = Color.white;
        shape.OutlineWidth = 2;
        shape.Outline.Color = Color.black;
        shape.Pointer = new PanelPointer { side = PointerSide.Top, position = .5f, width = 32, height = 16 };
        shape.PointerPosition = .75f;
        shape.OuterShadow.Enabled = true;
        shape.OuterShadow.Offset = new Vector2(0, -5);
        shape.OuterShadow.Blur = 0;
        shape.OuterShadow.Color = new Color32(20, 95, 8, 255);
        shape.AddOuterShadow(new PanelShadow
        {
            Enabled = true,
            Offset = new Vector2(0, -9),
            Blur = 16
        });
    }
}
```

`Pointer`, `BorderStroke` и `OutlineStroke` — структуры. Для изменения нескольких их полей присвойте структуру целиком. Для частых изменений доступны `PointerPosition`, `BorderPhase` и `OutlinePhase`. Тени можно добавлять, получать и удалять через `AddOuterShadow`, `GetOuterShadow`, `RemoveOuterShadow` и соответствующие методы для внутренних теней.

Для изменения ключей градиента с автоматическим обновлением используйте `shape.Fill.SetGradientKeys(...)` либо присвойте `shape.Fill.Gradient`. Старые поля с маленькой буквы и списки `AdditionalOuterShadows` / `AdditionalInnerShadows` сохранены. После прямых изменений этих полей и списков вызовите `Refresh()`.

## Ограничения и производительность

Компонент использует четыре вершины и один проход. До 64 активных плашек делят один материал и текстуры. Разные цвета, радиусы и градиенты в пределах одной страницы сами по себе не разделяют батч uGUI. Canvas, порядок отрисовки, stencil-маски и переход между страницами могут разделить батч. Пакет автоматически включает `TexCoord1` для Canvas, на которых используются плашки.

Изменённые страницы загружаются перед отрисовкой Canvas. Повторный `Refresh()` с теми же параметрами обходится без загрузки текстур. При повторном использовании слота атлас может сохранить прежнюю таблицу градиента. У однотонной заливки и четырёх одинаковых радиусов есть отдельные короткие пути в шейдере. Тени и обводки вычисляются только для включённых слоёв. Шейдер пропускает внутренние тени в центре плашки, если расстояние до края гарантирует прозрачную тень. Указатель рассчитывается только у плашек с включённым Pointer. Штрихи и точки вычисляются только в полосе рамки или контура. March и Pulse используют время шейдера и не требуют пересборки меша или обновления атласа каждый кадр. Большие тени увеличивают площадь отрисовки. Изменение цветовых ключей у градиента обновляет текстуру всей страницы, поэтому при массовой покадровой анимации проверяйте стоимость этой операции в Profiler. Текстуры одной страницы занимают 224 КиБ данных на GPU и хранят копию для обновлений на CPU.

Мягкость тени рассчитана по расстоянию до края плашки и визуально приближает эффект Figma. Градиенты используют таблицу из 256 значений. На элементе поддерживается до четырёх внешних и четырёх внутренних теней. Вызовы отрисовки и количество вершин от числа слоёв не меняются. Стоимость шейдера и площадь отрисовки растут с числом активных слоёв и их размером. Для layout и raycast используется прямоугольник RectTransform. Указатель может выходить за него визуально. При использовании самой панели в роли `Mask` у неё в stencil попадают видимые части, включая тень и outline.

## Обновление с UI Element

Встроенный пакет `com.rustamkhonoff.uielement` заменён на `com.rustamkhonoff.ushape`. Компонент теперь называется `RustamKhonoff.UShape.Shape`. GUID скрипта и сериализованные поля сохранены, поэтому компоненты и их стили в сценах и префабах сохраняются. В коде замените прежний namespace и тип.
